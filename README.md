# Lab 14 — Sets and Set Operations

## Course
CS 20 — Advanced Programming with C++

## Objective
This lab emphasizes a core abstract data type: the set. Students must implement a set of integers, support set operations, and analyze runtime behavior.

## Required tasks
Students must implement:

- unique insertion only;
- membership checks;
- deletion and clearing;
- conversion into a sorted vector;
- equality and subset checks;
- union, intersection, and difference operations;
- a complexity analysis of these operations.

## Deliverables
Students should submit:

- a working set implementation;
- a comprehensive unit test suite;
- a short analysis of set complexity and design trade-offs;
- clear comments explaining algorithmic decisions.

## Important note
The starter project intentionally leaves the core set logic unimplemented so students must complete the actual data structure logic and verify the behavior with tests.
